# DSA-Analysis-and-Design

What was the problem you were solving in the projects for this course?

The main problem I was solving was how to store, organize, and retrieve course information efficiently. In Project One, I analyzed different data structures and compared their runtime and memory usage to determine which one would work best for managing course data. In Project Two, I built a course planner program that loads course information from a CSV file, stores it in a binary search tree, prints the courses in alphanumeric order, and allows users to search for a specific course and view its prerequisites.

How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by first understanding the requirements of the program and then evaluating which data structure would best support those requirements. Learning about vectors, hash tables, and binary search trees helped me understand that different structures have different strengths and weaknesses. Since the program needed to print courses in sorted order and also support searching for individual courses, I chose a binary search tree because it provided an efficient way to organize and retrieve the data. Understanding data structures is important because choosing the right one can make a program faster, more efficient, and easier to work with.

How did you overcome any roadblocks you encountered while going through the activities or project?

One of the biggest challenges was getting the CSV data loaded correctly and making sure the binary search tree stored and displayed the courses properly. I also had to make sure the program could handle searching for courses and displaying prerequisites without errors. When I ran into issues, I reviewed my code, tested different inputs, and used feedback from assignments and course resources to figure out what was causing the problems. Breaking the project into smaller pieces made it easier to troubleshoot and complete each part successfully.

How has your work on this project expanded your approach to designing software and developing programs?

This project helped me think more carefully about planning before writing code. Instead of jumping straight into programming, I learned the importance of designing a solution first and considering which data structure would best meet the needs of the program. It also showed me how program performance can be affected by design decisions. Moving forward, I will spend more time evaluating possible solutions before beginning implementation.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

Working on these projects reinforced the importance of organizing code into separate functions and keeping it easy to read. I learned to use meaningful variable names, add comments where appropriate, and write code that is easier to update in the future. By structuring the program into smaller sections, it became easier to test and modify without affecting other parts of the code. These practices will help me create programs that are more maintainable, readable, and adaptable as projects become more complex.
